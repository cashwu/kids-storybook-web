## T0 前置驗證與邊界確認 ✅ 已完成
**目標**：確認已選技術能支援本書的文字、封面及朗讀，留下後續 task 可依循的模型、限制與已確認邊界。
**層級／狀態**：必要／已完成（2026-11-07）。專案骨架、文字與封面真實試驗、同網域與試驗部署、Workers Logs 檢查、輸入與逾時邊界、朗讀改用 `speechSynthesis`；結果見 PLAN 3.7 與第 5 節。
**依據**：PLAN 第 3.1、3.2、3.3、3.6、5 節。

### 範圍與工作項目
- 確認 Vite＋Vue 3＋TypeScript 與單一 Cloudflare Worker＋Static Assets 的最小開發／部署方式，驗證網頁與 API 同網域的可行性。
- 在具備授權與憑證後，以最小可拋棄試驗確認 OpenAI 文字、單張封面、單句英文語音的可用性；確認 Worker 能轉送回應。（語音依使用者決定改為 `speechSynthesis` 人工試聽，未呼叫 OpenAI 語音。）
- 記錄模型名稱、帳戶權限、實際等待時間／回應大小與可取得的費用資訊；區分實測、官方文件與尚未驗證，沒有數據就明記沒有。
- 檢查 Worker 與 SDK 的敏感資料記錄、自動重試設定；確認 key 不留存要求可落實。
- 依實測與平台限制提出輸入長度上限及各類請求逾時值；取得使用者確認後，將規則與邊界案例補入 PLAN 第 3、4、5 節，同步 T2–T5 的引用。
- 若驗證推翻方案，回報證據；涉及必要功能、費用或可觀察行為的更動，先確認，不暗換服務或縮小成功條件。

### 依賴與開工條件
無前置 task。調查可直接開始；實際 API 試驗前必須安全取得經授權的 OpenAI key，Cloudflare 試驗也需對應帳戶與部署權限。不得在聊天、文件或版本庫寫入憑證。
此任務負責解決已列出的驗證與邊界問題；缺少存取或尚未確認邊界時標明阻礙，不標為完成。

### 驗收
- 留下文字、封面兩類生成及 Worker 轉送的實測結果，包含成功／失敗與限制，以及 `speechSynthesis` 的人工試聽紀錄；不以文件推論替代真實試驗。
- PLAN 第 5 節列出仍未驗證項目及影響；必要可行性驗證通過、輸入／逾時邊界已確認才完成 T0。
- 後續任務可直接找到模型及已確認邊界，不需猜產品決策。檢查試驗檔案與日誌沒有 key。

- 以 `speechSynthesis`（PLAN 3.7）完成逐句播放／暫停、句子高亮、切頁停止與同時間只播放一句；朗讀控制抽成可注入假朗讀器的模組。
- 呈現裝置無法朗讀時的停用狀態與「由裝置內建的語音合成朗讀」標示，讓桌面及手機寬度可操作；配色與版面依 PLAN 第 3.4 節。

### 依賴與開工條件
T0 完成；測試故事可用。固定資料只供開發驗證，不當成線上成功生成的證據。

### 驗收

- 四頁標題及中英對照正確呈現，桌面與手機寬度可閱讀操作；建置成功。
- 記錄哪些驗收使用固定資料，保留真實生成與部署驗收至 T2–T5。

## T2 接入真實故事生成
**目標**：使用者輸入需求與自備 key 後，可取得並閱讀有效的四頁雙語故事。
**層級／狀態**：必要／受依賴阻擋。
**依據**：PLAN 第 3.1–3.3、3.6、3.7 節；A1 文字部分、A2–A4、A6 文字替換部分、A7 文字請求部分、A9。

### 範圍與工作項目
- 加入角色、生活情境與 key 輸入及已確認的輸入驗證；沒有年齡欄位，請求固定以 4–5 歲為對象；角色與情境預填 Demo 案例，key 不預填（PLAN 第 3.1 節）。
- 故事文字成功顯示後，輸入表單收合成「建立新故事」入口（PLAN 第 3.4 節）。
- 建立同網域 Worker 文字 API，按 PLAN 第 3.2 節轉送 key（只用 `Authorization` header、不轉送 OpenAI 錯誤原文、拒絕非 https；頁面在 http 開啟時導向 https），明示資料流與用量負擔；處理主機記錄與不快取敏感使用者資料的要求。文字模型與 reasoning effort 依 PLAN 3.7 由 Worker 環境變數設定。
- 生成並驗證故事頁數、句數、非空與雙語對應；固定介面呈現文字，不執行模型產生的程式。
- 完成文字生成狀態、禁止重複提交、有限逾時、手動重試與可能再次計費的說明；關閉自動付費重試。
- 文字失敗保留輸入與舊故事，文字成功且驗證通過才替換；此階段不呼叫尚未完成的素材 API。

### 依賴與開工條件
T0、T1 完成；文字模型、輸入長度與逾時邊界見 PLAN 3.7；真實 key 與測試權限可用。

### 驗收
- 真實生成完成 A1 文字部分，人工檢視角色、生活情境、初學英文及繁中對應。
- 驗證 A2–A4、A6 文字部分、A7 文字部分；失敗案例可用受控回應驗證，報告區分真實 API 與模擬。
- 依 A9 檢查 key 與故事僅在當頁、不同使用者資料隔離；檢查輸出、URL、持久儲存與日誌不洩漏 key。
**不做**：封面生成、保存與下載；T3、T4 再驗證朗讀與整體流程。

## T3 接入裝置語音朗讀
**目標**：真實生成的故事文字通過驗證後，每句可用裝置內建語音朗讀。
**層級／狀態**：必要／受依賴阻擋。
**依據**：PLAN 第 3.1、3.3、3.4、3.7 節；A1 朗讀部分、A5 無英文聲音部分、A6 替換時停止朗讀、A8。

### 範圍與工作項目
- 把 T1 的朗讀模組接到 T2 生成的故事；文字未通過驗證前不開放朗讀。
- 依 PLAN 3.7 選擇聲音（預設 en-US，其次任一 `en-*`）與語速（前端建置設定，預設 0.1）；不新增聲音或語速選單。
- 裝置不支援或沒有英文聲音時停用播放並說明；單句朗讀出錯時停止高亮、可再按一次。
- 替換為新故事時停止正在進行的朗讀，舊故事的高亮不留到新故事。

### 依賴與開工條件
T2 完成。不需要 OpenAI key 或 Worker API。

### 驗收
- 真實生成一個完整故事，在桌面與手機（含 iOS Safari）逐句朗讀，人工確認朗讀內容對應 A1 英文。
- 執行 A8：播放不重疊、暫停可用、切頁停止、無法朗讀時不能播放；A6 替換時停止朗讀。
- 以假朗讀器測試無英文聲音與朗讀錯誤路徑（A5 無英文聲音部分）。
**不做**：中文朗讀（選做 T8）、逐字對齊、選聲音、調語速選單、語音對話、OpenAI 語音或 Edge TTS。
