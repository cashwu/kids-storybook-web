# 生活情境雙語有聲故事書 — 實作計畫

日期：2026-11-06（2026-11-07 補入 T0 驗證結果與加分項 OpenAI 語音 3.8）。狀態：需求已確認；計畫與獨立 task 文件合併 Sol review APPROVE；T0 已完成，其驗證結果與朗讀方案變更另經 review（第 8 節）；其餘未開始實作。
本文件保留需求與驗收規則；工作拆分見 [task.md](./task.md)。

## 1. 問題與成功條件
家長希望把孩子遇到的生活情境與喜好，變成適齡、可一起閱讀的英文故事；目前 skill 要先提供逐頁故事，再由 agent 產生靜態練習網頁，沒有給一般使用者輸入情境後生成故事的 web app。
第一版服務 Hack Day 現場自備 OpenAI API key 的開發者。使用者能在部署的 HTTPS 網頁輸入喜歡的角色與生活情境，取得預設四頁（可選 4–10 頁）的中英對照故事、一張 AI 封面、逐句英文朗讀（裝置內建語音合成）。
核心成功：正常路徑能完成全書及播放；封面失敗不阻擋已生成文字的閱讀；可單獨重試封面。
Demo 案例：喜歡恐龍、第一次上學而害怕。產出以恐龍角色經歷上學情境的溫和故事，簡單英文與自然繁體中文逐句對應。

## 2. 不做清單
- 帳號、付款、雲端故事庫、公開分享：不影響本次單頁生成與閱讀。
- 上傳繪本、照片辨識、玩具照片：本次來源是生活情境文字，不擴大輸入模式。
- 逐頁 AI 插圖：只需一張封面，降低生成等待與跨頁角色一致性的工作。
- 逐字高亮、時間對齊：只做逐句高亮，不移植原有 word-boundary 流程。
- Edge TTS：不是公開服務，連線需要逆向產生 Microsoft 的 `Sec-MS-GEC`（DRM token），放進公開部署的 app 等於繞過其存取限制，且演算法一改就全部失效。
- 語音對話、選聲音、調語速、選年齡、英文難度選項、再次簡化按鈕：固定 4–5 歲對象、初學英文與部署設定的朗讀方式足以完成用途。
- 核心版不做中文朗讀：列為加分項（3.5），不阻擋核心驗收。
- 核心版不做 OpenAI 語音：列為加分項（3.8），核心驗收只用裝置語音。
- OpenAI 語音的延伸（3.8）：閱讀中自由切換朗讀方式（選擇放在生成表單，只保留失敗時的出口）；選 OpenAI 聲音、語速或語氣（由部署設定決定）；顯示金額估算或已請求句數（價格會變動，固定說明已足以告知會計費）；預先生成全書（使用者選逐頁生成，翻過才計費）；失敗時自動改用裝置語音（聲音突然改變，也容易混淆是否計費）；改接 Realtime API（只需撐過 Hack Day）；中文的 OpenAI 語音、在下載或保存中內嵌 OpenAI 音檔（要解決的是英文朗讀品質，T6–T8 仍用裝置語音）。
- 自動重試付費請求、背景工作恢復、多本故事並行：使用者確認只手動重試，生成期間不開新故事。
- 平台提供共用 API key：使用者自備，平台不代付。
- 核心版不保存故事、沒有下載：列為有順序的加分項，不阻擋核心驗收。
- 不直接執行整份 agent skill：抽取閱讀規則與資料驗證，建立固定介面和生成流程。

## 3. 已確認的行為
### 3.1 輸入與輸出
- 不提供年齡輸入，故事固定以 4–5 歲孩子為對象；喜歡的角色、生活情境必填。
- 第一版的角色與情境欄位預先填入 Demo 案例（恐龍；第一次上學，有點害怕和媽媽分開），方便測試，使用者可修改或清空；key 欄位一律空白，不預填。
- 英文固定初學程度；頁數預設 4 頁，使用者可在表單選 4–10 頁（使用者於 2026-11-07 確認新增，邊界見 3.7）；每頁固定 2 句英文（使用者於 2026-11-07 確認），每句有一對一繁體中文。
- 全書有標題及一張 AI 封面。內頁以文字為主。
- 先生成及驗證故事文字，確認頁數、每頁句數、雙語對應和非空內容，再開始封面請求與開放朗讀。
- 文字與封面使用 OpenAI；英文朗讀使用瀏覽器內建的 `speechSynthesis`，不經過 Worker 或 OpenAI、不計費。模型、聲音與語速見 3.7，不提供使用者模型、聲音或語速選單；加分項 3.8 的朗讀方式（裝置語音／OpenAI 語音）是唯一例外，仍不選聲音或模型。
- 固定閱讀介面呈現資料，模型不產生可執行網頁程式。

### 3.2 Key 與資料流
- 使用者輸入自己的 key；只保留在當頁記憶體，經 HTTPS 傳給本 app 後端，再呼叫 OpenAI。
- 畫面明確告知 key 與故事需求經過本 app 後端送往 OpenAI，API 用量由該 key 負擔。
- 後端不持久保存或記錄 key；key 不出現在 URL、log、錯誤回應、故事資料、瀏覽器儲存與匯出檔。
- 瀏覽器只用 `Authorization` header 把 key 送到 Worker，不放在自訂 header、query 或 body：Cloudflare 即時 log 會遮蔽 `Authorization`，但會完整記錄自訂 header 與 URL（5 節 T0 實測）。
- Worker 不把 OpenAI 的錯誤訊息原文轉給瀏覽器，只回本 app 定義的錯誤類別：OpenAI 的 401 訊息會帶回 key 開頭與末 4 碼。
- 頁面在 http 開啟時導向 https；Worker 收到非 https 的 `/api/*` 請求直接回錯誤，不轉送 OpenAI。workers.dev 的 http 網址不會自動轉 https（5 節 T0 實測）。本機開發的 loopback 位址（`localhost`、`127.0.0.1`、`[::1]`）例外，不導向也不拒絕：連線不經過外部網路，部署網址不會落入這個例外（T2 實作時整理，使用者已確認）。
- SDK、代理及主機的記錄設定也必須符合以上界線。不得宣稱 OpenAI 端零留存，本計畫只規範本 app。
- 核心版重新整理後，key 與故事消失，需要重新輸入和生成。
- 重新整理或關閉分頁前，若會損失東西就請瀏覽器顯示內建的離開確認視窗（使用者於 2026-11-07 確認）：文字或封面請求進行中、畫面上已有故事，或角色、情境改得和預填範例不同（清空不算）。只填 key 不確認：key 本來就設計成不留存。視窗文字由瀏覽器決定，無法自訂；手機瀏覽器關分頁或切 app 時常不觸發，只是提醒，不保證資料留住。

### 3.3 生成、失敗與重建
- 文字成功且驗證通過後請求封面，封面請求結束（成功或失敗）才把文字與封面一起顯示為新故事；等待期間（文字與封面）畫面只顯示「故事生成中」，不分開說明文字與封面，舊故事仍可閱讀。封面失敗時照樣顯示故事，封面位置顯示失敗並可單獨重試；重試期間封面顯示處理中（使用者 2026-11-07 確認：文字先出現、封面晚十幾秒才補上看起來不協調）。朗讀不需要生成，沒有處理中、失敗或重試狀態（加分項 3.8 的 OpenAI 語音除外）。
- 裝置不支援 `speechSynthesis` 或沒有任何英文聲音時，播放按鈕停用並說明原因，文字照常可讀。單句朗讀出錯時停止該句高亮、回到可播放狀態，使用者可以再按一次。
- 文字請求失敗、拒絕或輸出不合規格：視為文字生成失敗，不繼續請求素材，保留輸入供手動再試。
- 不自動重試任何付費請求（包含 SDK 的自動重試）；素材失敗只手動重試該素材，不重生文字或已成功素材。
- 遇到無效 key、權限不足、限流、網路問題或逾時，顯示可理解的失敗狀態，不暴露憑證。
- 逾時不代表 OpenAI 未處理；重試前說明可能再次計費，不承諾只計費一次。
- 仍有生成請求進行時，不另開新故事，也不重複提交同一素材；建立新故事期間（新故事顯示前）也不重試舊故事的封面：新故事發佈後結果會被丟棄，等於白付費（3.8 的語音同理）。每個請求必須能結束為成功或失敗，不能無限卡住。
- 新故事文字成功且驗證通過、封面請求也結束後才替換舊故事；文字失敗保留舊故事。新故事素材失敗時保留新故事文字。
- 新故事不得混入舊故事的封面或朗讀：替換故事時停止正在進行的朗讀。

### 3.4 閱讀
- 分頁瀏覽；每句提供英文播放與暫停，朗讀時高亮該句，不做逐字高亮。
- 同時間只有一句播放；播放另一句或切頁時停止前一句，切頁清除舊高亮。
- 裝置無法朗讀時不可播放（見 3.3）。
- 顯示中英文對照，標示朗讀「由裝置內建的語音合成朗讀」。
- 採可在桌面與手機寬度閱讀操作的介面。
- 故事文字成功並顯示後，輸入表單收合成「建立新故事」入口，展開才顯示表單；收合時閱讀區占滿主要版面，手機寬度同樣以閱讀為主。
- 介面配色採 Catppuccin Latte 淺色系；畫面不另外標示英文程度。版面參考 [ui-mockup.html](./ui-mockup.html)（草稿，非實作）。

### 3.5 加分項及交付界線
核心流程與重要失敗情境驗收通過後才評估剩餘時間；核心驗收不依賴任何加分項。
1. 先做下載單一 HTML：內含故事文字與封面，朗讀同樣使用開啟裝置的 `speechSynthesis`（沒有音檔可內嵌；只有裝置本機聲音能離線朗讀）；離線可翻頁，不含 key，不需伺服器。
2. 再做瀏覽器保存最近一本：重新整理可恢復閱讀，不保存 key。
3. 中文朗讀：以 `speechSynthesis` 的 zh-TW 聲音朗讀中文句子，不增加 API 請求或費用，語速沿用英文朗讀的建置設定；閱讀區上方切換本次朗讀語言（英文／中文），切換時停止目前播放並清除高亮；預設英文，選擇只在當頁記憶體，替換成新故事時沿用（替換時照常停止朗讀），重新整理回到英文。只用 zh-TW 聲音（lang 為 zh-TW 或 zh-Hant-TW 等同一地區的寫法）：沒有時不改用 zh-CN、zh-HK（粵語）或其他中文聲音，中文不能選並說明原因，英文朗讀不受影響；裝置有 zh-TW 但沒有英文聲音時仍可切到中文朗讀。朗讀中 zh-TW 聲音消失時停止朗讀並回到英文。朗讀標示涵蓋中文。使用者 2026-11-07 指定 T5 通過後先做，排在 4、1、2 之前。
4. OpenAI 語音：規則見 3.8；在第 3 項之後做，之後才做 1、2。
1、2 項目前只確認目標（先後已確認），尚非可直接開工的完整 task。開始前需確認：素材未齊是否允許下載、覆蓋最近一本的時間點、儲存失敗與刪除行為；中文朗讀的未決事項已確認（見第 3 項）。未確認前不自行補規則；若當天沒時間釐清就不做，不影響核心交付。

### 3.6 已確認的技術選擇
- 前端採 Vite＋Vue 3＋TypeScript，負責輸入表單、分頁閱讀、`speechSynthesis` 朗讀與生成狀態；不使用 React。
- 使用單一 Cloudflare Worker＋Workers Static Assets：Static Assets 提供前端編譯檔案，同一個 Worker 的 `/api/*` 處理 OpenAI 請求。前端與 API 同網域、同一專案部署，不另外建立 Pages 專案。
- API 分為故事文字與單張封面兩類請求；瀏覽器管理進度，Worker 處理各次請求，封面有獨立狀態並可單獨重試。朗讀在瀏覽器完成，不經過 Worker；加分項 3.8 的 OpenAI 語音例外，由同一個 Worker 新增單句語音請求。
- 核心版以 Vue 內建響應式狀態管理當頁資料，暫不引入 Pinia 或 Vue Router；單頁流程不需要額外狀態管理或路由套件。
- 核心版不使用 D1、KV 或 R2；故事與封面返回瀏覽器，後端不建立故事儲存服務。key 的傳送與不留存要求沿用 3.2。
- 加分項的離線 HTML 匯出與最近一本保存也先在瀏覽器完成，不為此新增雲端儲存。其產品規則仍須依 3.5 確認。
- 此處記錄架構選擇，不代表已完成 Cloudflare 部署、API 相容性或限制驗證。

### 3.7 T0 確認的模型與邊界
以下由使用者於 2026-11-07 依 T0 實測確認；實測數據見第 5 節。
- **故事文字**：Responses API，模型 `gpt-6-luna`、reasoning effort `medium`，Structured Outputs（`json_schema`，strict），`store: false`。模型與 reasoning effort 由部署設定（Worker 環境變數 `OPENAI_TEXT_MODEL`、`OPENAI_TEXT_REASONING_EFFORT`）調整，不是使用者選單；未設定時用上述預設值。要調整時寫在 `wrangler.jsonc` 的 `vars`：dashboard 設定的變數可能在下次 `wrangler deploy`（含 Workers Builds）時被覆蓋。
- **封面**：Images API，模型 `gpt-image-2.6-flare`，動態 GIF（`output_format: "gif"`，預設 9 張影格），尺寸 `512x512`，品質 `low`。1024x1024 搭配 9 張影格會超過像素上限而回 400，不可使用。GIF 需要帳戶具備 GIF preview 權限。
- **朗讀**：瀏覽器內建 `speechSynthesis`，每句一個 utterance；按下播放就高亮該句，不等 `start` 事件（讓暫停鈕立即可用），由該句的 `end`／`error` 事件清除高亮；`lang` 為 `en-US`。聲音用裝置的預設 en-US 聲音，沒有就用任一 `en-*` 聲音。語速由前端建置設定調整，預設 `0.1`。各裝置的聲音與實際最低語速不同（使用者試聽時 0.1 與 0.3 在部分裝置上差異不大），這是已接受的限制。OpenAI 語音以加分項提供，規則見 3.8。
- **輸入上限**：去除頭尾空白後，角色 1–30 字元、生活情境 1–100 字元，字元以 Unicode code point 計算（前端與 Worker 相同；中文字、英文字母各算 1，組合 emoji 可能算成多個）；key 必填、不得含空白、最多 200 字元；頁數必填，為 4–10 的整數，預設 4。超過上限不送出生成請求，並指出需要修正的欄位。
- **逾時**：Worker 對 OpenAI 的請求上限為文字 60 秒、封面 120 秒；加分項 OpenAI 語音（3.8）單句 30 秒。瀏覽器對 Worker 的逾時各多 10 秒，讓 Worker 的逾時錯誤先回到前端。逾時一律結束為失敗，不自動重試。
- **OpenAI 呼叫方式**：Worker 直接用 `fetch` 呼叫 OpenAI REST API，不引入 `openai` SDK，因此沒有 SDK 內建重試（預設 2 次）或 SDK log 需要關閉；每個請求以 `AbortSignal.timeout` 套用上述逾時。
- **轉送方式**：成功的封面回應（約 1.5 MB 的 base64 JSON）由 Worker 串流轉送，不在 Worker 內解碼；Free 方案每個請求只有 10 ms CPU 時間，等待 OpenAI 的時間不計入。

### 3.8 加分項：OpenAI 語音朗讀
以下由使用者於 2026-11-07 確認。要解決的問題：裝置內建語音（例如 Safari 的 Samantha）品質不夠好，使用者可選擇改用更自然的 OpenAI AI 語音，並清楚知道會用自己的 key 額外計費。核心驗收不依賴本節。
- **選擇**：生成表單新增「朗讀方式」，選項為裝置語音（預設）與 OpenAI 語音。值只在當頁記憶體，建立新故事時沿用表單上次的值，重新整理回到裝置語音。閱讀中不提供切換，例外見「出口」。選裝置語音的故事行為與 3.3、3.4 相同，不送任何語音請求。
- **費用說明**：選 OpenAI 語音時，選項旁固定顯示：會用你的 key 呼叫 OpenAI 語音，每頁第一次開啟時為該頁每句計費一次，重播不再計費，實際費用以 OpenAI 帳單為準。不顯示金額。這本書的閱讀區朗讀標示改為「由 OpenAI 的 AI 語音朗讀」（OpenAI 要求揭露語音為 AI 產生）。
- **生成時機**：故事文字通過驗證後，與封面請求同時請求第 1 頁每句的語音；封面與第 1 頁語音請求都結束（成功或失敗）才和文字一起顯示為新故事（同 3.3，使用者 2026-11-07 確認），失敗的句子照下方「失敗」與「出口」處理，不阻擋顯示。之後每進入一個尚未請求過的頁面，就請求該頁每句。每句一個請求。成功的音檔留在當頁記憶體，重播與翻回該頁不再請求；翻過全書最多為每句請求一次（手動重試除外）。
- **生成中**：該句播放鍵停用並顯示「生成中」，完成後由使用者按下播放，不自動播放。翻頁不取消已送出的請求，完成後保留。
- **失敗**：單句失敗時該句顯示可理解的失敗原因（不含 key），同頁其他句不受影響；再按該句即手動重試，重試前說明可能再次計費。不自動重試、不自動改用裝置語音。
- **出口**：這本書任一句 OpenAI 語音失敗後，閱讀區顯示「這本書改用裝置語音」。使用者按下後，這本書之後一律用裝置語音（3.3、3.4、3.7），不再送語音請求、不能切回 OpenAI 語音，也不重新生成文字或封面；朗讀標示改回裝置語音。裝置沒有英文聲音時依 3.3 停用並說明。
- **播放**：沿用 3.4 與 T1 的行為：同時間只播一句，再按正在播的句子停止並回到句首，切頁停止並清除高亮。
- **隔離**：語音請求屬於 3.3 的生成請求：仍有語音請求進行時，不能送出新故事。建立新故事期間（等文字、封面或第 1 頁語音），舊故事不送任何新的語音請求：不能重試失敗的句子，翻到尚未請求過的頁面也不請求，這些句子的播放鍵停用；已取得音檔的句子照常播放。新故事文字失敗後恢復：只補送目前所在頁尚未請求的句子，期間翻過的其他頁等再次進入才請求（使用者 2026-11-07 確認）。替換故事時停止播放、清除舊故事的音檔；舊故事的語音回應不得出現在新故事。
- **Key 與逾時**：沿用 3.2；Worker 對 OpenAI 單句語音逾時 30 秒，瀏覽器 40 秒，逾時結束為失敗。Worker 只轉送單句英文文字，不轉送 OpenAI 錯誤原文。
- **模型與期限**：OpenAI `/v1/audio/speech` 的 `gpt-4o-mini-tts`；聲音、語氣指示與語速由部署設定決定，不是使用者選單，預設值在 T9 開工前試聽後確認。官方公告該模型 2027-01-06 停用，本功能只保證在此之前可用；停用後請求失敗即依「失敗」與「出口」處理，不改接 Realtime API。

## 4. 核心驗收範例
A1 正常路徑：輸入恐龍／第一次上學與有效 key → 四頁，每頁 2 句初學英文及一對一繁中；一張封面，每句能朗讀，朗讀內容對應該句；人工確認故事有回應角色、生活情境且適齡。
A2 輸入邊界：角色或情境只有空白時不送出生成請求，指出需要修正的欄位；角色 31 字元或情境 101 字元（去除頭尾空白後）同樣不送出並指出欄位，30／100 字元可送出；頁數空白、3、11 或非整數不送出並指出欄位，4／10 可送出，預設為 4，生成的故事頁數與所選相同；畫面沒有年齡欄位，送出的需求固定以 4–5 歲為對象。
A3 無效 key：文字請求失敗後保留輸入，沒有封面請求、不開放朗讀；更正 key 後可手動再試，任何畫面與 log 不洩漏 key。OpenAI 回 401 且訊息含 key 片段（例如 `sk-test-****0000`）時，Worker 的回應只有本 app 的錯誤類別，不含該片段。
A4 格式錯誤／拒絕：回傳頁數與所選不同（例如選 4 頁卻回三頁）、某頁不是 2 句、空英文或缺翻譯 → 視為文字失敗，不將不完整文字發佈為新故事，不請求封面。
A5 部分失敗：封面失敗 → 全書文字可讀、每句可朗讀；手動重試只請求封面，文字不受影響。裝置沒有英文聲音 → 播放按鈕停用並說明，文字與封面不受影響。
A6 重建：已有故事 A，建立故事 B → B 文字失敗仍可讀 A；B 文字成功後等封面期間仍讀 A 與 A 的封面，封面結束才換成 B，B 封面失敗仍讀 B，不顯示 A 的封面；A 正在朗讀時替換成 B 會停止朗讀。
A7 重複與逾時：生成中再次操作不多送新故事或封面請求；逾時進入失敗，保留可用內容，無自動重試，手動重試告知可能再次計費。
A8 播放：播第一句再播第二句，不重疊；切頁立即停止並清除舊句高亮；裝置無法朗讀時不能播放；畫面有「由裝置內建的語音合成朗讀」標示。
A9 記憶體與隔離：重新整理後核心版沒有故事或 key；不同使用者不能拿到彼此資料；瀏覽器持久儲存、URL、回應、日誌及靜態產物沒有 key。
A10 部署：實際 HTTPS 網址完成 A1、A5、A8，桌面與手機寬度可操作；失敗訊息不含 key。未執行的驗收必須如實列出，不能以 mock 成功替代真實 API 驗證。

### 加分項驗收範例：OpenAI 語音（3.8，T9）
V1 預設：開啟頁面，表單朗讀方式為裝置語音；生成故事後沒有任何語音請求，標示為「由裝置內建的語音合成朗讀」。
V2 正常路徑：選 OpenAI 語音、生成恐龍故事 → 文字通過驗證後，與封面同時送出第 1 頁每句一個語音請求；封面與第 1 頁語音都結束才一起出現；翻到其他頁時，該頁語音完成前播放鍵顯示「生成中」且停用；完成後按播放聽到該句英文 AI 語音並高亮；再按播放重播同句不再送請求。表單選項旁有費用說明，閱讀區標示為「由 OpenAI 的 AI 語音朗讀」。人工試聽確認比裝置語音自然。
V3 翻頁：第 2 頁語音仍在生成時翻到第 3 頁 → 送出第 3 頁請求，第 2 頁請求不取消；翻回第 2 頁不再請求。所有頁都翻過後（不論所選頁數），語音請求總數等於全書句數。
V4 單句失敗：第 2 頁第 2 句逾時 → 該句顯示失敗，第 1 句可正常播放；按第 2 句先說明可能再次計費，之後只重送這一句；沒有自動重試，也沒有改用裝置語音。
V5 出口：key 額度不足，每句語音都失敗 → 閱讀區出現「這本書改用裝置語音」；按下後每句用裝置語音朗讀，不再送語音請求，文字與封面不變、沒有重新生成，標示改回裝置語音。
V6 文字失敗：選 OpenAI 語音但文字失敗或驗證不通過 → 新故事沒有語音請求，也沒有封面請求。
V7 隔離：故事 A（OpenAI 語音）第 3 頁語音生成中 → 「建立新故事」無法送出，直到請求結束；建立故事 B 期間翻到 A 尚未請求過的第 4 頁 → 不送語音請求、該頁播放鍵停用，按 A 失敗的句子也不重試，已有音檔的頁照常播放；B 文字失敗且仍停在第 4 頁時才送出第 4 頁請求；A 某句播放中，另外建立故事 C 成功 → A 停止播放，C 第 1 頁另行請求，C 不會播出 A 的音檔。
V8 Key：OpenAI 對語音請求回 401 且訊息含 key 片段 → Worker 回應只有本 app 的錯誤類別；key 只在 `Authorization`，不出現在畫面、URL、log 或回應。
V9 沿用與重設：上一本選 OpenAI 語音，展開「建立新故事」時表單仍是 OpenAI 語音；重新整理後回到裝置語音。

### 加分項驗收範例：中文朗讀（3.5 第 3 項，T8）
Z1 預設與切換：開啟故事，朗讀語言為英文，按播放念英文；英文第 1 句朗讀中切到中文 → 立即停止並清除高亮，再按第 1 句念「恐龍有一個新書包」這類對應的中文句子並高亮，不送任何 API 請求。
Z2 沒有 zh-TW：裝置只有 en-US 與 zh-CN 聲音 → 「中文」不能選並說明裝置沒有台灣中文語音，英文照常朗讀；不用 zh-CN 聲音念中文。
Z3 只有中文聲音：裝置有 zh-TW 但沒有英文聲音 → 英文模式顯示無法朗讀；切到中文後可以朗讀中文。
Z4 沿用：中文模式下建立新故事 B 成功 → A 的朗讀停止，B 仍是中文模式；重新整理後回到英文。
Z5 聲音消失：中文朗讀中 zh-TW 聲音從清單消失 → 停止朗讀、清除高亮並回到英文。
