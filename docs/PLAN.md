# 生活情境雙語有聲故事書 — 實作計畫

日期：2026-11-06。狀態：需求已確認；計畫與獨立 task 文件合併 Sol review APPROVE；未開始實作。
本文件保留需求與驗收規則；工作拆分見 [task.md](./task.md)。

## 1. 問題與成功條件
家長希望把孩子遇到的生活情境與喜好，變成適齡、可一起閱讀的英文故事；目前 skill 要先提供逐頁故事，再由 agent 產生靜態練習網頁，沒有給一般使用者輸入情境後生成故事的 web app。
第一版服務 Hack Day 現場自備 OpenAI API key 的開發者。使用者能在部署的 HTTPS 網頁輸入喜歡的角色與生活情境，取得四頁中英對照故事、一張 AI 封面、逐句英文朗讀。
核心成功：正常路徑能完成全書及播放；素材失敗不阻擋已生成文字的閱讀；可單獨重試失敗素材。
Demo 案例：喜歡恐龍、第一次上學而害怕。產出以恐龍角色經歷上學情境的溫和故事，簡單英文與自然繁體中文逐句對應。

## 2. 不做清單
- 帳號、付款、雲端故事庫、公開分享：不影響本次單頁生成與閱讀。
- 上傳繪本、照片辨識、玩具照片：本次來源是生活情境文字，不擴大輸入模式。
- 逐頁 AI 插圖：只需一張封面，降低生成等待與跨頁角色一致性的工作。
- 逐字高亮、時間對齊、Edge TTS：已選 OpenAI 語音和逐句高亮，不移植原有 word-boundary 流程。
- 語音對話、選聲音、選年齡、調頁數、英文難度選項、再次簡化按鈕：固定 4–5 歲對象、初學英文與單一朗讀聲音足以完成用途。
- 核心版不做中文朗讀：列為加分項（3.5），不阻擋核心驗收。
- 自動重試付費請求、背景工作恢復、多本故事並行：使用者確認只手動重試，生成期間不開新故事。
- 平台提供共用 API key：使用者自備，平台不代付。
- 核心版不保存故事、沒有下載：列為有順序的加分項，不阻擋核心驗收。
- 不直接執行整份 agent skill：抽取閱讀規則與資料驗證，建立固定介面和生成流程。

## 3. 已確認的行為
### 3.1 輸入與輸出
- 不提供年齡輸入，故事固定以 4–5 歲孩子為對象；喜歡的角色、生活情境必填。
- 第一版的角色與情境欄位預先填入 Demo 案例（恐龍；第一次上學，有點害怕和媽媽分開），方便測試，使用者可修改或清空；key 欄位一律空白，不預填。
- 英文固定初學程度；四頁，每頁 1–2 句英文，每句有一對一繁體中文。
- 全書有標題及一張 AI 封面。內頁以文字為主。
- 先生成及驗證故事文字，確認頁數、每頁句數、雙語對應和非空內容，再開始圖片及語音請求。
- 圖片與語音均使用 OpenAI，具體模型於實作開始時驗證帳戶可用性、費用與等待時間；不提供模型選單。
- 固定閱讀介面呈現資料，模型不產生可執行網頁程式。

### 3.2 Key 與資料流
- 使用者輸入自己的 key；只保留在當頁記憶體，經 HTTPS 傳給本 app 後端，再呼叫 OpenAI。
- 畫面明確告知 key 與故事需求經過本 app 後端送往 OpenAI，API 用量由該 key 負擔。
- 後端不持久保存或記錄 key；key 不出現在 URL、log、錯誤回應、故事資料、瀏覽器儲存與匯出檔。
- SDK、代理及主機的記錄設定也必須符合以上界線。不得宣稱 OpenAI 端零留存，本計畫只規範本 app。
- 核心版重新整理後，key 與故事消失，需要重新輸入和生成。

### 3.3 生成、失敗與重建
- 文字成功且驗證通過後即可閱讀；封面和各句語音分別顯示處理中、成功或失敗狀態。
- 文字請求失敗、拒絕或輸出不合規格：視為文字生成失敗，不繼續請求素材，保留輸入供手動再試。
- 不自動重試任何付費請求（包含 SDK 的自動重試）；素材失敗只手動重試該素材，不重生文字或已成功素材。
- 遇到無效 key、權限不足、限流、網路問題或逾時，顯示可理解的失敗狀態，不暴露憑證。
- 逾時不代表 OpenAI 未處理；重試前說明可能再次計費，不承諾只計費一次。
- 仍有生成請求進行時，不另開新故事，也不重複提交同一素材。每個請求必須能結束為成功或失敗，不能無限卡住。
- 新故事文字成功且驗證通過才替換舊故事；文字失敗保留舊故事。新故事素材失敗時保留新故事文字。
- 新故事不得混入舊故事的封面或音訊。

### 3.4 閱讀
- 分頁瀏覽；每句提供英文播放與暫停，朗讀時高亮該句，不做逐字高亮。
- 同時間只有一句播放；播放另一句或切頁時停止前一句，切頁清除舊高亮。
- 尚未成功生成的音訊不可播放；其他成功音訊可正常播放。
- 顯示中英文對照，標示語音為 AI 生成。
- 採可在桌面與手機寬度閱讀操作的介面。
- 故事文字成功並顯示後，輸入表單收合成「建立新故事」入口，展開才顯示表單；收合時閱讀區占滿主要版面，手機寬度同樣以閱讀為主。
- 介面配色採 Catppuccin Latte 淺色系；畫面不另外標示英文程度。版面參考 [ui-mockup.html](./ui-mockup.html)（草稿，非實作）。

### 3.5 加分項及交付界線
核心流程與重要失敗情境驗收通過後才評估剩餘時間；核心驗收不依賴任何加分項。
1. 先做下載單一 HTML：內含故事文字、封面與音檔；離線可翻頁及播放，不含 key，不需伺服器。
2. 再做瀏覽器保存最近一本：重新整理可恢復閱讀，不保存 key。
3. 中文朗讀：文字成功後，每句的英文與中文語音一起產生（語音請求數為核心版的兩倍，語音費用隨之增加）；閱讀區上方切換本次朗讀語言（英文／中文），切換時停止目前播放並清除高亮；各句各語言的語音分別顯示狀態、可單獨手動重試，AI 語音標示涵蓋中文。與 1、2 的先後順序尚未決定。
這三項目前只確認目標（1、2 的先後已確認），尚非可直接開工的完整 task。開始前需確認：素材未齊是否允許下載、覆蓋最近一本的時間點、儲存失敗與刪除行為；中文朗讀與 1、2 的先後、中文聲音的選型、中文語音沿用單句語音 API 的方式，以及下載與保存是否包含中文音檔。未確認前不自行補規則；若當天沒時間釐清就不做，不影響核心交付。

### 3.6 已確認的技術選擇
- 前端採 Vite＋Vue 3＋TypeScript，負責輸入表單、分頁閱讀、音訊播放與生成狀態；不使用 React。
- 使用單一 Cloudflare Worker＋Workers Static Assets：Static Assets 提供前端編譯檔案，同一個 Worker 的 `/api/*` 處理 OpenAI 請求。前端與 API 同網域、同一專案部署，不另外建立 Pages 專案。
- API 分為故事文字、單張封面與單句語音三類請求；瀏覽器管理進度，Worker 處理各次請求，支援文字先閱讀及素材個別重試。既有生成與失敗規則不變。
- 核心版以 Vue 內建響應式狀態管理當頁資料，暫不引入 Pinia 或 Vue Router；單頁流程不需要額外狀態管理或路由套件。
- 核心版不使用 D1、KV 或 R2；故事、封面與音訊返回瀏覽器，後端不建立故事儲存服務。key 的傳送與不留存要求沿用 3.2。
- 加分項的離線 HTML 匯出與最近一本保存也先在瀏覽器完成，不為此新增雲端儲存。其產品規則仍須依 3.5 確認。
- 此處記錄架構選擇，不代表已完成 Cloudflare 部署、API 相容性或限制驗證。

## 4. 核心驗收範例
A1 正常路徑：輸入恐龍／第一次上學與有效 key → 四頁，每頁 1–2 句初學英文及一對一繁中；一張封面，每句能播放，語音內容對應該句；人工確認故事有回應角色、生活情境且適齡。
A2 輸入邊界：角色或情境只有空白時不送出生成請求，指出需要修正的欄位；畫面沒有年齡欄位，送出的需求固定以 4–5 歲為對象。
A3 無效 key：文字請求失敗後保留輸入，沒有圖片或音訊請求；更正 key 後可手動再試，任何畫面與 log 不洩漏 key。
A4 格式錯誤／拒絕：回傳三頁、空英文或缺翻譯 → 視為文字失敗，不將不完整文字發佈為新故事，不生成素材。
A5 部分失敗：封面及第 2 頁第 1 句音訊失敗 → 全書文字可讀，其他完成音訊可播；分別手動重試只請求該封面或該句，已完成內容不受影響。
A6 重建：已有故事 A，建立故事 B → B 文字失敗仍可讀 A；B 文字成功則換成 B，B 封面失敗仍讀 B，不顯示 A 的封面或播放 A 音訊。
A7 重複與逾時：生成中再次操作不多送新故事或相同素材請求；逾時進入失敗，保留可用內容，無自動重試，手動重試告知可能再次計費。
A8 播放：播第一句再播第二句，不重疊；切頁立即停止並清除舊句高亮；未就緒語音不能播放；畫面有 AI 語音標示。
A9 記憶體與隔離：重新整理後核心版沒有故事或 key；不同使用者不能拿到彼此資料；瀏覽器持久儲存、URL、回應、日誌及靜態產物沒有 key。
A10 部署：實際 HTTPS 網址完成 A1、A5、A8，桌面與手機寬度可操作；失敗訊息不含 key。未執行的驗收必須如實列出，不能以 mock 成功替代真實 API 驗證。
